# 🍔 Online Food Delivery System (OFDS)

This is a group project for the Foundation of Software Engineering course.

The project focuses on analyzing and designing an online food delivery system that connects customers, restaurants, delivery drivers, and system administrators.

System Features

* User registration and login
* Browse restaurants and menus
* Place and manage food orders
* Order tracking
* Online payment and cash on delivery
* Order cancellation and ratings
